# QUANT TERMINAL — 加密貨幣自動交易機器人儀表板

單一 HTML 檔案的合約交易機器人操作介面。**零相依套件**,下載後用瀏覽器直接打開即可執行。

> ⚠️ **儀表板本身是模擬器,但搭配 `rust-backend` 後可以用真實資金下單。**
>
> - 只開網頁 → 純模擬,不會碰到任何真實資金
> - 加上 Rust 後端(唯讀模式)→ 顯示交易所真實餘額,仍不會下單
> - 後端設定 `LIVE_TRADING=true` + `DRY_RUN=false` → **會用真實資金在交易所下單**
>
> 最後一項預設關閉,而且**網頁上的任何按鈕都無法開啟它**,必須手動編輯後端 `.env`。
> 開啟前請務必讀完「風險聲明」與 [`rust-backend/README.md`](rust-backend/README.md)。

## 快速開始

```bash
git clone https://github.com/doki03164/quant-terminal.git
```

**Windows 一鍵啟動:對 `start.cmd` 按兩下。** 它會自動編譯(首次)、啟動後端、再開啟儀表板。

或只開網頁:直接打開 `crypto-bot-dashboard.html`(純模擬,不含真實資產顯示)。

> 網頁為什麼不能自己啟動後端?因為 `file://` 頁面若能執行本機程序,等於任何網站都能在你電腦上跑程式。
> 這是瀏覽器的安全設計,所以由 `start.cmd` 代勞。

**設定會自動沿用**:後端若已設好金鑰,重新整理網頁時交易所會自動連線,不需要每次重接。
策略參數存在瀏覽器,下次開啟自動套用。金鑰的真實來源永遠是後端的 `.env` —— 網頁只是反映它的狀態,
後端金鑰若被移除,網頁也會跟著顯示斷線,不會停在過期的畫面。

想顯示**交易所真實資產**或讓機器人**自動下單**,再另外啟動 Rust 後端 —— 完整步驟見
[`rust-backend/README.md`](rust-backend/README.md)。

**啟動機器人:** 設定 → 隨意填入 API Key/Secret → 按「測試」→ 打開開關 → 回主控台按「啟動策略」。

## 功能

### 三個頁面

| 頁面 | 用途 |
|---|---|
| **主控台** | 即時行情、機器人狀態、持倉、最近交易 |
| **設定** | 交易所連線、策略開關、風險規則 |
| **回測** | 最長 20 年的長期模擬與績效統計 |

### 即時行情(真實資料)

透過 **Binance 公開 WebSocket** 取得 BTC / ETH / SOL 的真實報價:

- 逐筆推送的即時價格、24h 漲跌、高低點、成交量
- WebSocket 失敗時自動改用 REST 每 5 秒輪詢
- 斷線自動重連(退避間隔遞增)
- 可一鍵關閉,關閉後完全不連外部伺服器

公開行情端點允許瀏覽器直連,**不需要 API 金鑰**。需要簽章的私有端點(下單、查餘額)
瀏覽器無法安全處理,那部分必須由後端伺服器代簽。

### Rust 後端(選用)

`rust-backend/` 是一個簽章代理服務。瀏覽器無法安全保管交易所密鑰,所以密鑰放伺服器端。

| 功能 | 說明 |
|---|---|
| 真實資產顯示 | 讀取 Binance / Bitget 合約帳戶餘額 |
| 自動下單 | 市價進場 + 自動掛上止損 / 止盈 |
| 三道安全鎖 | `LIVE_TRADING` 總開關、`DRY_RUN` 乾跑、單筆名目上限 |

**預設完全關閉。** 儀表板上的任何按鈕都無法開啟實盤下單 —— 必須手動編輯後端 `.env` 並重啟服務。

下單前的伺服器端驗證(不通過就拒絕):沒有止損、止損在錯誤方向、止盈在錯誤方向、超過名目上限、數量非正數或非有限值。

啟動教學:[`rust-backend/README.md`](rust-backend/README.md)

### 雙策略引擎

**策略一:七關趨勢交易法(4H)**

依序通過七道關卡,任何一關不過就跳過該標的:

| 關卡 | 檢查內容 |
|---|---|
| 1 · 結構過濾 | 4H 至少 3 個同向 HH/HL 或 LH/LL 標籤 |
| 2 · 趨勢成熟度 | 早期 / 中期可做,成熟末段跳過 |
| 3 · 多週期對齊 | D1 方向需與 4H 一致;W1 需為明確趨勢 |
| 4 · 進場區 HPCZ | 至少 3 項共振,且必須含 25 或 50 EMA |
| 5 · 風險計算 | 止損 ≥ 2×ATR、盈虧比 ≥ 1:2、單筆風險 ≤ 1% |
| 6 · 確認 K 棒 | 順勢 pin bar 或吞噬形態(需已收線) |
| 7 · 執行 | 同時掛出止損與止盈 |

方向看週線、空間看日線、執行在 4H。執行週期可切換 1H / 4H。

**真實市場樣本外回測**(2022-08 ~ 2026-07,12 個標的):189 筆、每週 0.91 筆、
勝率 33.3%、獲利因子 1.23、期望值 +0.181R、最大回撤 −16.8%、零強制平倉。
樣本內(2018–2022)為期望值 +0.353R —— 退化但未崩潰,是真實修正而非過度擬合的特徵。

**策略四:海龜交易法(4H / 15m)**

Dennis / Eckhardt 的公開規則(Curtis Faith 記載):20 期唐奇安通道突破進場、10 期反向出場(系統一),
或 55 期進、20 期出(系統二)。N = ATR(20),停損 2N,倉位按每 N 風險固定比例。
系統一保留「前次突破若獲利則跳過」的濾網 —— 拿掉它會改變整個系統的性格。

**低勝率、高盈虧比**的設計:靠許多次小虧損換少數幾波大趨勢。

**策略五:RSI2 均值回歸(15m)**

Larry Connors 的 2 期 RSI 回歸法,含長均線趨勢濾網。股票日線的公開回測宣稱
[75–79% 勝率](https://www.quantifiedstrategies.com/connors-rsi/)。

⚠️ **但那個數字在 15m 加密貨幣上不成立** —— 見下方實測。

**策略二:雙均線系統(15m + 4H)**

金叉做多、死叉做空,兩個週期各自獨立運作,各自用自己的 ATR 計算止損。
另有三道濾網抑制盤整假訊號:成交量倍數、ADX 門檻、同週期結構方向一致。

### 風險控制

固定不可調整的規則:

- **20× 逐倉**,單筆風險 ≤ 1%
- 止損 ≥ 2×ATR(14),最低盈虧比 1:2
- 保證金使用率上限 80%
- 止損若寬於強平距離則**直接拒絕該筆設定**

自動停止條件(觸發後只停開新倉,既有持倉的止損止盈仍有效):

- 當日虧損 2% → 當日暫停
- 當週虧損 5% → 當週暫停
- 連續 3 筆虧損 → 冷卻
- 單日最多 2 筆

### 回測引擎

- 最長 20 年、每 15 分鐘一根 K 棒(10 年約 35 萬根 / 每個標的)
- 直接呼叫實盤引擎的同一套策略程式碼,不是另外重寫的版本
- 可選市場情境:中性 / 偏多 / 偏空 / 盤整
- 種子可重現,交易明細可匯出 CSV
- 統計:年化報酬、最大回撤、夏普、索提諾、獲利因子、期望值 R、月報酬熱圖

## 10 年回測結果(僅供參考,見下方警語)

中性情境 · 種子 `decade-01` · $10,000 起始:

| 指標 | 數值 |
|---|---|
| 總報酬 | +778%($10,000 → $87,826) |
| 年化報酬 | 24.3% |
| 最大回撤 | −39.3%(水下 1,437 天) |
| 交易筆數 | 1,492(每週 2.86 筆) |
| 勝率 / 獲利因子 | 42% / 1.32 |
| 期望值 | +0.216R |
| 強制平倉 | 0 |
| 手續費 | $32,435 |

> 上表為**合成資料**。真實市場的樣本外數字請看上方七關趨勢法段落 —— 差距很大。

### 這個數字幾乎是循環論證

模擬器產生的價格序列**在設計上就帶有持續性趨勢**——漲跌方向會連續維持數百根 K 棒。
趨勢跟隨策略在這種資料上獲利幾乎是必然的。上面的曲線主要證明了**模擬器會走趨勢**,
而不是策略有優勢。

同一份設定改成「盤整」情境後,年化報酬掉到 **5.8%**、夏普從 1.28 掉到 **0.42**,
風控觸發次數增加一半。這兩次執行之間的落差,才是「多少結果來自模型、多少來自方法」的誠實衡量。

另外兩個容易被忽略的數字:**水下將近 4 年**,以及**手續費吃掉毛利的 29%**
(20× 的名目部位很大,5bps 也很傷)。

## RSI2 實測:一個「高勝率」宣稱的反例

使用者要求一個「15 分鐘、收入穩定、高勝率、高盈虧比」的策略。我照文獻實作了 Connors RSI2,
然後用真實市場資料驗證。結果如下(6 個標的、2024-07 ~ 2026-07、1,500 筆):

| 指標 | 文獻宣稱(股票日線) | **實測(15m 加密貨幣)** |
|---|---|---|
| 勝率 | 75–79% | **52.2%** |
| 獲利因子 | — | **0.92**(< 1 = 虧損) |
| 期望值 | — | **−0.024R** |
| 總報酬 | — | **−75.2%** |
| 最大回撤 | ~34% | **−79.3%** |

**這個策略在 15m 加密貨幣上是虧錢的。** 保留它不是因為它有用,是因為它是一個誠實的反例。

三個原因:

1. **文獻是股票日線,不是 15m 加密貨幣。** 別的市場、別的週期的統計不會自動轉移。
2. **高勝率與高盈虧比在數學上互斥。** 均值回歸的獲利了結目標很近(平均獲利 0.93R),
   代價是偶爾吃到大虧(平均虧損 −1.07R)。想同時要高勝率和高盈虧比,是在要求一件不存在的東西。
3. **交易頻率殺死它。** 每週 14.4 筆 × 20× 槓桿 × 雙邊手續費 —— 光是成本就把 52% 勝率的微小優勢吃光。

如果你只從這份專案帶走一件事:**任何策略的宣稱數字,都要在你自己要交易的市場與週期上重新驗證。**

## 技術說明

- 單一 HTML 檔,手寫 CSS + 原生 JavaScript,**無任何 CDN 或建置流程**
- 基礎資料為 15m,其餘週期(1H / 4H / D1 / W1)由固定網格聚合而來,週期之間不會互相矛盾
- 指標為自行實作:EMA、Wilder ATR、Wilder ADX、擺動高低點偵測、HH/HL/LH/LL 結構標記
- 深色終端機風格,配色沿用原始交易手冊的設計語彙

## 風險聲明

本專案**僅供教育與程式展示用途**,不構成投資、財務或交易建議。

- 所有成交、餘額、損益與回測結果均為**模擬資料**,不能證明任何策略會獲利
- 槓桿合約有極高的全額虧損風險。**20× 之下,逆向約 5% 即遭強制平倉**;
  跳空、資金費率或交易所故障都可能造成超出預期的損失
- 過往績效(無論模擬或實際)都不代表未來結果
- 請只使用你能承受全部虧光的資金,必要時諮詢持牌財務顧問

實盤前應先完成至少 100 筆手動回測與一整個月的模擬盤紀錄,
並把**執行紀律**看得比損益更重要——執行率低於 90% 時,任何獲利數字都沒有分析價值。

### 開啟自動下單前必讀

- 策略樣本外的**最長連續虧損是 16 筆**。你會親身經歷,而那時你會非常想關掉系統
- 期望值 +0.181R 在 189 筆下是 **2.5σ**,是訊號但**不是證明**
- 回測**尚未計入滑價與資金費率**,20× 之下這兩項很可能吃掉那個期望值
- 下單路徑**未經真實交易所驗證**,請務必先在測試網跑通
