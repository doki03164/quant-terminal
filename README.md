# QUANT TERMINAL — 加密貨幣自動交易機器人儀表板

單一 HTML 檔案的合約交易機器人操作介面。**零相依套件**,下載後用瀏覽器直接打開即可執行。

> ⚠️ **這是模擬器,不是實盤交易系統。** 所有成交、餘額與資金曲線都由本機隨機模型產生,
> 不會連線交易所下單。唯一的真實資料是即時報價(Binance 公開行情)。
> 詳見下方「風險聲明」。

---

## 快速開始

```bash
git clone https://github.com/doki03164/quant-terminal.git
```

用瀏覽器打開 `crypto-bot-dashboard.html` 即可。不需要 npm、不需要架伺服器、不需要編譯。

**啟動機器人:** 設定 → 隨意填入 API Key/Secret → 按「測試」→ 打開開關 → 回主控台按「啟動策略」。

## 功能

### 三個頁面

| 頁面 | 用途 |
|---|---|
| **主控台** | 即時行情、機器人狀態、持倉、最近交易 |
| **設定** | 交易所連線、策略開關、風險規則 |
| **回測** | 最長 20 年的長期模擬與績效統計 |

### 即時行情(真實資料)

透過 **Binance 公開 WebSocket** 取得 BTC / ETH / SOL 的真實報價:

- 逐筆推送的即時價格、24h 漲跌、高低點、成交量
- WebSocket 失敗時自動改用 REST 每 5 秒輪詢
- 斷線自動重連(退避間隔遞增)
- 可一鍵關閉,關閉後完全不連外部伺服器

公開行情端點允許瀏覽器直連,**不需要 API 金鑰**。需要簽章的私有端點(下單、查餘額)
瀏覽器無法安全處理,那部分必須由後端伺服器代簽。

### 雙策略引擎

**策略一:七關趨勢交易法(4H)**

依序通過七道關卡,任何一關不過就跳過該標的:

| 關卡 | 檢查內容 |
|---|---|
| 1 · 結構過濾 | 4H 至少 3 個同向 HH/HL 或 LH/LL 標籤 |
| 2 · 趨勢成熟度 | 早期 / 中期可做,成熟末段跳過 |
| 3 · 多週期對齊 | D1 方向需與 4H 一致;W1 需為明確趨勢 |
| 4 · 進場區 HPCZ | 至少 3 項共振,且必須含 25 或 50 EMA |
| 5 · 風險計算 | 止損 ≥ 2×ATR、盈虧比 ≥ 1:2、單筆風險 ≤ 1% |
| 6 · 確認 K 棒 | 順勢 pin bar 或吞噬形態(需已收線) |
| 7 · 執行 | 同時掛出止損與止盈 |

方向看週線、空間看日線、執行在 4H。這套流程刻意設計成**拒絕率極高**——
10 年回測中僅觸發 29 筆。

**策略二:雙均線系統(15m + 4H)**

金叉做多、死叉做空,兩個週期各自獨立運作,各自用自己的 ATR 計算止損。
另有三道濾網抑制盤整假訊號:成交量倍數、ADX 門檻、同週期結構方向一致。

### 風險控制

固定不可調整的規則:

- **20× 逐倉**,單筆風險 ≤ 1%
- 止損 ≥ 2×ATR(14),最低盈虧比 1:2
- 保證金使用率上限 80%
- 止損若寬於強平距離則**直接拒絕該筆設定**

自動停止條件(觸發後只停開新倉,既有持倉的止損止盈仍有效):

- 當日虧損 2% → 當日暫停
- 當週虧損 5% → 當週暫停
- 連續 3 筆虧損 → 冷卻
- 單日最多 2 筆

### 回測引擎

- 最長 20 年、每 15 分鐘一根 K 棒(10 年約 35 萬根 / 每個標的)
- 直接呼叫實盤引擎的同一套策略程式碼,不是另外重寫的版本
- 可選市場情境:中性 / 偏多 / 偏空 / 盤整
- 種子可重現,交易明細可匯出 CSV
- 統計:年化報酬、最大回撤、夏普、索提諾、獲利因子、期望值 R、月報酬熱圖

## 10 年回測結果(僅供參考,見下方警語)

中性情境 · 種子 `decade-01` · $10,000 起始:

| 指標 | 數值 |
|---|---|
| 總報酬 | +778%($10,000 → $87,826) |
| 年化報酬 | 24.3% |
| 最大回撤 | −39.3%(水下 1,437 天) |
| 交易筆數 | 1,492(每週 2.86 筆) |
| 勝率 / 獲利因子 | 42% / 1.32 |
| 期望值 | +0.216R |
| 強制平倉 | 0 |
| 手續費 | $32,435 |

### 這個數字幾乎是循環論證

模擬器產生的價格序列**在設計上就帶有持續性趨勢**——漲跌方向會連續維持數百根 K 棒。
趨勢跟隨策略在這種資料上獲利幾乎是必然的。上面的曲線主要證明了**模擬器會走趨勢**,
而不是策略有優勢。

同一份設定改成「盤整」情境後,年化報酬掉到 **5.8%**、夏普從 1.28 掉到 **0.42**,
風控觸發次數增加一半。這兩次執行之間的落差,才是「多少結果來自模型、多少來自方法」的誠實衡量。

另外兩個容易被忽略的數字:**水下將近 4 年**,以及**手續費吃掉毛利的 29%**
(20× 的名目部位很大,5bps 也很傷)。

## 技術說明

- 單一 HTML 檔,手寫 CSS + 原生 JavaScript,**無任何 CDN 或建置流程**
- 基礎資料為 15m,其餘週期(1H / 4H / D1 / W1)由固定網格聚合而來,週期之間不會互相矛盾
- 指標為自行實作:EMA、Wilder ATR、Wilder ADX、擺動高低點偵測、HH/HL/LH/LL 結構標記
- 深色終端機風格,配色沿用原始交易手冊的設計語彙

## 風險聲明

本專案**僅供教育與程式展示用途**,不構成投資、財務或交易建議。

- 所有成交、餘額、損益與回測結果均為**模擬資料**,不能證明任何策略會獲利
- 槓桿合約有極高的全額虧損風險。**20× 之下,逆向約 5% 即遭強制平倉**;
  跳空、資金費率或交易所故障都可能造成超出預期的損失
- 過往績效(無論模擬或實際)都不代表未來結果
- 請只使用你能承受全部虧光的資金,必要時諮詢持牌財務顧問

實盤前應先完成至少 100 筆手動回測與一整個月的模擬盤紀錄,
並把**執行紀律**看得比損益更重要——執行率低於 90% 時,任何獲利數字都沒有分析價值。
